# Agent Implementation Guides

These guides are task briefs for future coding agents. Each guide defines scope, prerequisites, implementation requirements, forbidden shortcuts, tests, and handoff expectations.

## How to use

1. Read the root [AGENTS.md](../../AGENTS.md).
2. Read [ARCHITECTURE.md](../../ARCHITECTURE.md).
3. Confirm the active phase in [ROADMAP.md](../implementation/ROADMAP.md).
4. Read only the relevant guide(s) for the assigned phase.
5. Inspect the current code and tests before implementing.
6. Do not implement later phases merely because a guide exists.
